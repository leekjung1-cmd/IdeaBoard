아이디어 보드 — 사용법

1. 이 폴더(IdeaBoard)를 원하는 곳에 통째로 풀어 두세요. (예: D:\IdeaBoard)
   _internal 폴더는 지우면 안 됩니다.
2. IdeaBoard.exe 를 실행하세요. 설치할 것은 없습니다.
   바탕 화면에 두고 쓰려면 exe를 우클릭 → 보내기 → 바탕 화면에 바로 가기 만들기.
3. 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면
   [추가 정보] → [실행] 을 누르세요. (서명 안 된 직접 만든 프로그램이라 뜨는 경고입니다)

기록(데이터) 위치와 업데이트
- 아이디어·기획서·기능·메모·설정은 사용자 폴더에 저장됩니다:
    %APPDATA%\IdeaBoard   (왼쪽 위 ⋯ → '데이터 폴더 열기')
  그래서 새 버전을 어느 폴더에 풀어도 예전 기록을 그대로 씁니다.
- 새 버전으로 업데이트: 새 zip을 풀고 새 IdeaBoard.exe 를 실행하면 끝.
  (예전 폴더는 지워도 됩니다. 버전이 바뀌면 처음 켤 때 자동 백업도 하나 떠 둡니다 → backups 폴더)
- 1.0.0 전 버전은 exe 옆 data 폴더에 저장했어요.
  · 새 버전을 같은 폴더에 덮어 풀면 처음 켤 때 자동으로 가져옵니다.
  · 다른 폴더에 풀었다면: ⋯ → '예전 데이터·백업 가져오기' → 예전 폴더의 data\ideas.db 선택.
    (가져오기는 '합치기'라서 지금 기록은 그대로 두고, 같은 항목은 더 최근에 고친 쪽이 남습니다)
- 버전은 창 제목과 왼쪽 아래에 보입니다.
- 윈도우 10/11 (64비트) 전용입니다.

주요 조작
- Ctrl+N: 새로운 아이디어 · Ctrl+F: 검색 · Ctrl+T: 일정표
- 대시보드: 칩을 누르면 열리고, 끌어서 옮기면 중요도·긴급도가 바뀜 (아래 미분류 칸에 놓으면 지워짐)
- 기획서: 칸 제목을 눌러 바로 고치기, ⋯ 메뉴로 위/아래·삭제, 맨 아래 ＋ 칸 추가
- 필요한 기능: 적고 Enter, 끝나면 체크, ⋯ 메뉴로 중요도·순서 바꾸기
- 메모: Enter 로 추가 (줄바꿈은 Shift+Enter), 메모 ⋯ 메뉴로 고치기·기획서 칸에 넣기·기능으로 추가·삭제
- 아이디어 ⋯: 클로드로 보내기 / 마크다운으로 내보내기 · 🔗 클로드 세션: 연결한 세션 바로 열기
- 왼쪽 위 ⋯: 모든 아이디어 내보내기 · 백업 · 예전 데이터 가져오기 · 데이터 폴더 열기
- 왼쪽 목록 '보기 ▾': 상태·용도별로 숨기기, 정렬 바꾸기
